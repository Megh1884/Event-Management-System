Event Management API Django + DRF

Minimal UI to guide HR/reviewers: explore the browsable API, access admin, and obtain JWT tokens for authenticated endpoints.

API Root

Browse available endpoints via Django REST Framework UI.

Open /api/

Admin Panel

Manage users, events, RSVPs, and reviews (login required).

Open /admin/

Get JWT Token

POST your username/password to obtain an access token.

Open /api/auth/token/

Events Endpoint

List, create, and manage events (auth required for write).

Open /api/events/
Tip: create a superuser with python manage.py createsuperuser to log into admin and test JWT.
